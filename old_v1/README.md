- За шкалою з умови (MSE < 35, MAE < 5, R² > 0.8) усі три метрики фінальної моделі мають рівень «відмінно».
- Бутстреп-інтервали (95 %) на тесті: MSE ≈ 14.9-34.3, MAE ≈ 2.7-3.8, R² ≈ 0.87-0.94.
- Validation фінальної моделі: MSE 17.99, MAE 2.90, R² 0.938 (оцінка оптимістична, бо val використано для вибору); train: MSE 4.03, R² 0.984.
- Різниця між НМ і Gradient Boosting (+2.5 МПа²) статистично незначуща (парний бутстреп, 95 % ДІ ≈ [−4.1; +10.0]).
- На нових рецептурах (групове розбиття за складом суміші) НМ має MSE 33.2, R² 0.890, тобто краще за GBM (36.4, R² 0.879).

## Обрана конфігурація

- Дані: видалено 25 повних дублікатів (1030 → 1005); стратифіковане розбиття 70 / 15 / 15 (703 / 151 / 151), `random_state = 42`; `StandardScaler` навчено лише на train; ціль у МПа (не масштабується).
- Ознаки: 7 компонентів суміші + `LogAge = log1p(Age)` (набір `log_age`).
- Архітектура: `ConcreteNet(nn.Module)` зі схемою `in → Linear(64) → ReLU → Linear(32) → ReLU → Linear(1)` (≈ 2.7 тис. параметрів), bias виходу ініціалізовано середнім `y_train`.
- Навчання: `nn.MSELoss`, Adam (lr = 0.01), batch 32 (`DataLoader`, `shuffle=True`, `num_workers=0`), до 1000 епох з ранньою зупинкою за val MSE (patience 100, повертається найкращий `state_dict`); ансамбль seed 42 / 7 / 2024 (найкращі епохи 137 / 271 / 298).

## Основні висновки

- Найважливіші фактори (permutation importance на тесті): для НМ це Cement, Age, Slag (далі FlyAsh), для Gradient Boosting Age, Cement, Water. Цемент і вік входять у топ-2 обох моделей. Суперпластифікатор діє опосередковано (через зменшення води), це видно з пласкої кривої часткової залежності.
- Криві часткової залежності: ≈ +15 МПа на кожні 100 кг цементу; логарифмічне зростання з віком до ≈ 100 діб; спад міцності при воді > ≈ 160 кг/м³.
- Обмеження: малий датасет (427 унікальних рецептур), шум повторних вимірювань 1-8 МПа та аномалії (напр., 22.9 vs 55.9 МПа для однієї суміші), мало даних для віку > 100 діб і міцності > 70 МПа; лінійний вихід може давати від'ємні прогнози поза областю даних.
- Ідеї покращення: GroupKFold-крос-валідація, перенавчання на train+val, більший ансамбль / стекінг з GBM, `Softplus`-вихід або прогноз log(Strength), ознака W/B (вода / в'яжуче), Huber loss, планувальник lr.
