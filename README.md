# ДЗ 1 (тема 4): прогноз міцності бетону

Здавати: `dz_topic_4_Джафарлі_Фарід.ipynb`. У полі здачі написати `1` (перший підхід).

Результат фінальної моделі (Adam, lr 0.01, шари 128 і 64) на тесті: MSE 28.8, MAE 3.82, R² 0.885. Базова модель (SGD, lr 0.01, шари 64 і 32): MSE 26.6, MAE 3.59, R² 0.894. Обидві в зоні "відмінно".

Інші файли:
- `build_notebook.py` збирає ноутбук;
- `data/ConcreteStrengthData.csv` дані (якщо файлу немає, ноутбук завантажує їх з Kaggle);
- `dump_outputs.py` перевіряє, що в ноутбуці немає помилок;
- `old_v1/` попередня, розширена версія.

Перезапуск (близько 30 секунд на CPU):

```bash
../.venv/bin/python build_notebook.py
../.venv/bin/jupyter nbconvert --to notebook --execute --inplace dz_topic_4_Джафарлі_Фарід.ipynb
```
